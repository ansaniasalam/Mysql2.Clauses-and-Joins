# MySQL Clauses and Joins

Hands-on practice querying employee data with MySQL clauses, aggregate functions, and joins.

## What this covers

- Selecting distinct values and using column aliases
- Filtering records with `WHERE` and comparison operators
- Updating missing values
- Sorting and limiting query results with `ORDER BY` and `LIMIT`
- Summarizing data with `SUM`, `MIN`, `MAX`, `AVG`, and `COUNT`
- Grouping results with `GROUP BY` and filtering groups with `HAVING`
- Combining employee, department, and location data with `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`

## Data

The queries use an employee database with `Employees`, `Departments`, and `Location` tables. The database and sample records should be created and populated before running these queries.
